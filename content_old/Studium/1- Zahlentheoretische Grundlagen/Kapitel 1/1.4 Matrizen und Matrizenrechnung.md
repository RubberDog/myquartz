
### 1.4.1 Vektoren und Matrizen

Im Zweidimensionalen Raum besteht ein Vektor aus zwei Koordinaten, im m-Dimensionalen Raum besteht er aus m Koordinaten:

[img[Bilder\vektor1.png]]

Wichtige Eigenschaften von Vektoren:

1. Ein Vektor besteht aus einer Spalte und m Zeilen mit je einer Koordinate. Die Anzahl der Zeilen wird durch die Dimension des betrachteten Raumes vorgegeben.

2. Für die Symbolisierung von Vektoren werden Kleinbuchstaben in Fett genutzt. 

3. In der Literatur werden Vektoren auch mit Pfeilen gekennzeichnet (z.b. kleiner Pfeil über einem v)

4. Mehrere Vektoren können zu einer Matrix zusammengefasst werden, wobei eine Spalte als Vektor angesehen werden kann.
Bei n Vektoren aus einem m-dimensionalen Raum hat die Matrix somit m Zeilen und n Spalten.

### 1.4.3 Spezielle Matrizen

Um mit Matrizen zu rechnen muss der Typ beachtet werden.

Eine Matrix mit m Zeilen und n Spalten ist vom Typ (m,n) - auch Format genannt.

__Quadratische Matrix__

Anzahl der Zeilen gleich Anzahl der Spalten.

__Einheitsmatrix__

Eine besondere quadratische Matrix, welche nur Einsen auf der Hauptdiagonale und Nullen in allen anderen Positionen aufweist.

In der Literatur hat sie oft das Symbol I oder E;

![[vektor3.png]]

__Zeilenvektor / Spaltenvektor__

Ein Zeilenvektor ist eine Matrix vom Typ (1,n) mit einer Zeile und n Spalten.

Dem gegenüber ein Spaltenvektor, eine Matrix vom Typ (n, 1) mit n Zeilen und nur einer Spalte.

__Transponieren:__

Schreibt man die Koordinaten eines Spaltenvektors als Zeile auf, erhält man einen Zeilenvektor.

Den Tausch der Zeilen- und Spaltendarstellung nennt man Transponieren.

Ändert man einen Vektor a, indem man die Spalte als Zeile bzw umgekehrt anordnet, erhält man den transponierten Winkel a^T.

Ein transponierter Vektor wird mit einem T oder einem Apostroph versehen.

### 1.4.4 Rechnen mit Vektoren und Matrizen

__Addition und Subtraktion von Vektoren__

Zwei Vektoren können addiert oder subtrahiert werden, wenn sie vom selben Typ sind.

D.h. es können nur Zeilen- oder nur Spaltenvektoren mit der identischen Elementanzahl addiert oder subtrahiert werden.

Hierbei werden die Elemente an den gleichen Positionen der Vektoren miteinander addiert oder subtrahiert.

__Multiplikation eines Vektors mit einem Skalar__

Ein Vektor a kann mit jeder beliebigen Zahl ⋋, einem so genannten Skalar, multipliziert werden. Dazu wird jedes Element des Vektors mit dem Skalar multipliziert.

__Skalarprodukt von Vektoren__

Vektoren können miteinander multipliziert werden, wenn sie den gleichen Typ haben. (Transponierte Vektoren bedenken!)
