#### Rekursion
- Rekursion bedeutet, die Lösung eines Problems auf sich selbst zurückzuführen 
- Etwas bezieht sich direkt oder indirekt auf sich selbst
- Beispiel Fakultät berechnen; 

```
factorial(): 
	if n <= 1; then 
		return 1 
	else 
		return n * factorial(n - 1)
		
```
